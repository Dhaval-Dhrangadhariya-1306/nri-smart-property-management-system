# NRI Smart Property Management System

A full-stack web application designed to help Non-Resident Indians (NRIs) remotely manage, monitor, secure, and maintain their properties in India.

## Project Structure

- frontend/ — React + Vite frontend application
- backend/ — Node.js + Express backend API
- docs/ — Project documentation

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- JavaScript

### Database
- MongoDB
- Mongoose
- MongoDB Atlas

### Planned Advanced Features
- JWT authentication
- Role-based access control
- Real-time notifications
- Property monitoring
- Maintenance management
- Security and incident management
- Expense analytics
- AI-powered property insights
- Maps
- Cloud file storage
